# robin - twitter likes search Chrome Extension
![icon.png](icon.png)

Robin is a small Chrome extension that adds fast search to your Twitter/X likes. It lets you jump straight to a specific liked tweet by text or username, or scroll to the bottom of your likes page really fast without doing it by hand.

## how to use:
I havent published this extension to the chrome web store because i just dont see people using it, i made this for myself.

if you want to use this extension:
1. Clone this repo
2. Open the extensions page in your browser
3. Turn on developer mode
4. Click on Load Unpacked Extension
5. Select this folder

   ---

scroll to the bottom of your likes page really fast, or find a specific liked tweet.
